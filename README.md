# Карта складів Wildberries і Ozon у РФ

Інтерактивна карта фулфілмент-мережі двох маркетплейсів станом на липень 2026.

**Демо:** https://gastra0.github.io/wb-ozon-warehouses-map/

## Що показано

- **42 склади** — 23 Wildberries (рожеві) і 19 Ozon (сині)
- **Розмір кружка** — клас об'єкта: хаб / великий / регіональний
- **Блоки** — 10 регіонів, де більше одного складу, зведені під спільним підписом
- **🔥 Вогник** — склад згорів або сильно пошкоджений (Електросталь, Котовськ, Краснодар, Невинномиськ)
- **Бурштинове кільце** — влучання поруч, склад уцілів (Коледіно)

Наведення на кружок відкриває картку: клас, площа (де підтверджена), статус і пояснення.
Керування: колесо — зум, перетягування — зсув.

## Технічне

Один самодостатній HTML-файл, ~46 КБ, **без жодних зовнішніх залежностей** —
контур країни намальовано інлайновим SVG у конічній проєкції Альберса,
шрифти системні. Працює офлайн.

## Джерела

Адреси й склад мережі — публічні дані для продавців (WB Партнери, Ozon Seller).
Дані про атаки 18–22 липня 2026 — BBC, Meduza, Ведомости, Lenta, Коммерсантъ.
Розміри кружків відображають відносний клас складу, а не точні м².
